主题: Azure 计划维护将影响您中国北部 3（数据中心）的虚拟机服务 - Planned maintenance for your Azure Virtual Machine Service in China North 3

 

 

 [for English readers, please click here to view English version]

Tracking ID: HRMR-MKG

 

 

关于网络计划维护将影响部分中国北部 3（数据中心）的虚拟机的通知

 

您收到此通知是因为您正在使用Azure虚拟机。

 

即将到来的维护更新将于北京时间2026年7月12日21:50至2026年7月15日21:50进行，在此期间会影响您位于中国北部 3区域的虚拟机。计划维护期间虚拟机底层网络硬件设备将进行替换更新。维护开始后，每台虚拟机将至多出现15分钟不可用。系统磁盘及数据磁盘将保留，但临时磁盘将被重置。

 

受影响的虚拟机列表请查看此邮件的Account Information部分。

 

为自行控制虚拟机受影响的时段，您可参考以下步骤通过Azure门户或PowerShell迁移您的部署。请您于北京时间2026年7月12日21:50前完成迁移操作。

 

通过Azure门户迁移

 

对于经典和Azure 资源管理器模型的虚拟机：

  1. 登录Azure门户并导航至您希望迁移的虚拟机。
  2. 点击“停止”以停止虚拟机并取消分配。请确保虚拟机状态已变为“已停止(已取消分配)”。
  3. 在上一步状态切换完成后，点击“开始”。

 

对于虚拟机规模集：

  1. 登录Azure门户并导航至您希望迁移的虚拟机规模集。
  2. 选择需要迁移的虚拟机规模集并在左侧设置菜单选择“实例”。
  3. 选择需要迁移的虚拟机。
  4. 点击“解除分配”以停止虚拟机并解除分配。请确保虚拟机状态已变为“已停止(已取消分配)”。
  5. 在上一步状态切换完成后，点击“开始”。

 

通过Azure PowerShell迁移

 

请在Azure PowerShell中调用下列去除“StayProvisioned”标记的命令以关闭虚拟机。

 

对于经典模型的虚拟机，了解更多关于如何关闭虚拟机。

对于Azure 资源管理器模型的虚拟机，了解更多关于如何关闭虚拟机。

[English Version]

Scheduled network maintenance may affect one or more of your virtual machines in China North 3

 

You're receiving this notice because you currently use Azure Virtual Machines.

 

An upcoming maintenance update will affect virtual machines in China North 3 from 12 July 2026 21:50 CST until 15 July 2026 21:50 CST. During this planned maintenance window, IaaS virtual machines will be migrated to newer network hardware. Please expect each virtual machine to be unavailable for up to 15 minutes after initiating the maintenance. Operating system and data disks will be retained, but temporary disks will be reset.

 

See a list of your affected virtual machine(s) in the Account Information section of this email.

 

For more control over when your virtual machines will be affected, migrate your deployments using the following steps for the Azure portal or PowerShell. You must complete the migration prior to 12 July 2026 21:50 CST.

 

Migrate using the Azure portal

 

For both Classic and Azure Resource Manager (ARM) virtual machines:

  1. Log into the Azure portal and navigate to the virtual machines you want to migrate.
  2. Select “Stop” to stop and deallocate the virtual machine. Please ensure the virtual machine's status has transitioned to “Stop (deallocated)”.
  3. Select “Start” only after the previous change in status has completed.

 

For virtual machine scale sets:

  1. Log into the Azure portal and navigate to the virtual machine scale sets.
  2. Select a virtual machine scale set and select “Instances” from the left-side settings menu.
  3. Select the virtual machine you want to migrate.
  4. Select “Deallocate” to stop and deallocate the virtual machine. Please ensure the virtual machine’s status has transitioned to “Stop (deallocated)”.
  5. Select “Start” only after the previous change in status has completed.

 

Migrate using PowerShell

 

In Azure PowerShell, invoke the command to stop a virtual machine without a “StayProvisioned” flag.

 

For Classic virtual machines, learn more about stopping a virtual machine.

For ARM virtual machines: learn more about stopping a virtual machine.

 

More information

  • Types of maintenance performed on virtual machines  
  • Receive in-virtual machine notification 15 minutes prior to a virtual machine reboot

 

You can view this notification in the Azure portal under event ID: HRMR-MKG

 

Support options if you have additional questions:

  • Login to Azure Portal and navigate to the “Help + support” page to obtain technical support
  • Submit support request online: https://support.azure.cn/en-us/support/support-azure/
